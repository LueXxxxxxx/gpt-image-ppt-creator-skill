# 视觉提示词模板

## 风格确认页 Prompt 模板

生成一张 16:9 风格确认图，图中包含 4-6 个 PPT 缩略页预览。

必须包含：

- 已确认的 PPT 主题和目标受众
- 用户选择保留的页面定位类型
- 已选择的视觉风格方向
- 色彩体系
- 字体气质
- 版式网格和页边距系统
- 编号体系
- 内容页左上角主标题的位置和样式
- 目录页、过渡页、内容页标题的统一处理方式
- 图标、图表、插画、信息图的视觉语言

必须说明：这些缩略页应体现同一套 PPT 视觉系统，而不是互不相关的海报设计。

## 最终单页 Prompt 模板

```text
生成一张单张 16:9 完整 PPT 页面图像。
内部页序号：{number}，仅用于生成进度和文件命名，不要渲染为页面中的可见文字。
整体风格：{confirmed_style}
一致性参考：严格参考已确认的风格确认页。
编号体系：{numbering_style}，仅适用于目录页、过渡页和内容页标题中已经明确写出的编号。
页面定位：{role}
信息密度目标：{density}
内容页标题模式：{content_title_mode}
主标题文字："{main_title}"
副标题文字："{subtitle}"
正文文字：{body}
结论文字："{conclusion}"
视觉构图：{visual_intent}
页面定位专属约束：{role_constraints}
关键要求：文字清晰可读，无错别字，不要添加额外虚构文字，只输出一张完整 PPT 页面图像。
```

封面页追加：

```text
封面页不得出现页码、章节编号或装饰性数字角标，例如左上角的 01。只呈现主标题、副标题和已确认的短要点。
```

内容页追加：

```text
内容页主标题必须固定在左上角，并与其他内容页保持相同的位置、字号、样式和颜色处理；只允许标题文本变化。
内容页标题层级必须与其他内容页一致。
默认模式：内容页主标题使用不带模块序号的具体内容标题。
用户要求时的替代模式：内容页主标题使用“模块序号 + 模块标题”，并用次级标题呈现具体内容标题。
不要在某些内容页使用“编号+模块标题”，另一些内容页只使用具体标题；除非用户明确要求混用。
如果主标题只是模块标题，必须出现具体内容次级标题，不能只呈现模块标题本身。
当 content_title_mode 为 topic-only 时，不要在内容页主标题中显示模块序号或模块标题。
当 content_title_mode 为 module-plus-topic 时，内容页必须同时显示主标题和次级标题。
```

过渡页追加：

```text
只展示一个章节/模块标题和极少量辅助视觉元素。信息量至少比内容页减少一半。
这是过渡页系列的一部分。第一张已确认过渡页是过渡页母版。
必须严格参考第一张过渡页母版生成；最近一张已确认过渡页仅作为辅助一致性参考。
后续过渡页只允许修改章节编号、章节标题、背景图像、装饰图片和少量辅助元素。
不得修改标题区布局、编号样式、编号位置、标题位置、标题基线、字体设计、字号、字体颜色、发光/描边效果、分割线位置、标题容器形状、标题块比例、主视觉结构和页面留白。
不要改成内容页版式，不要改变标题排版，不要改变字体风格。
```

目录页追加：

```text
目录页中的所有目录项默认是同级并列关系。每一项的编号、标题、图标、容器、颜色、对比度、发光强度和强调程度应保持一致或非常接近。不要因为某一项位于最后、靠近页面下方或视觉上适合收尾，就使用橙色、反差色、重点色或更强发光效果。只有当大纲或用户明确标注某一项为重点、核心、主线、优先关注时，才允许单独高亮该项。
```

封面页和尾页追加：

```text
页面保持简洁、克制、专业，不要加入说明性长段落，不要出现页码或装饰性数字角标。
```
